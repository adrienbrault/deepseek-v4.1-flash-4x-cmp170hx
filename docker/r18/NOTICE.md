# r18 image sources

The [recipe notices](../../THIRD_PARTY.md) give the donor repositories, source revisions and licences for the engine, plugins, schedulers and native kernels. The staged context uses the same notices and licences for its vendor trees. In particular, vllm-exl3 and its r18 integration patches are **AGPL-3.0-only**. Include its corresponding source and notices when distributing a modified integration or image.

This directory records the [v0.34.0 port and serving layers](../../docs/PATCHES.md). The [reproduction guide](../../docs/REPRODUCING.md) lists the external context and runtime inputs.
